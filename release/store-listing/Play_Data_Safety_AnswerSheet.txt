RECOMMENDED ANSWER (matches the actual shipped build)

Q: Does your app collect or share any of the required user data types?
A: NO
------------------------------------------------------------------------

Why "No" is accurate for PlaceWell:
  - All label data (names, contents, notes, PHOTOS, room/zone, freshness
    dates, brand) is stored ONLY on the device (AsyncStorage + local
    files). Google counts data as "collected" only if it is transmitted
    off the device. Yours is not.
  - The build contains NO analytics SDK, NO crash-reporting SDK, and NO
    advertising SDK. The Firebase Analytics wrapper is inert because the
    @react-native-firebase/analytics package is not installed, so no
    analytics events are ever sent.
  - The only network call is the QR lookup:
        GET https://placewell.app/api/qr/lookup/{labelId}-{signature}
        GET https://placewell.app/api/qr/order/{orderId}
    It sends ONLY the scanned label/order ID plus a static app token.
    No account, no user ID, no device ID, no personal data. This does
    not map to any of Google's user-data categories.
  - No account, login, or email is required or collected.

After you select NO, the form skips the data-type and security
questions. Review and submit.

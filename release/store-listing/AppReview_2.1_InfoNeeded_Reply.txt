3. APP FUNCTION & TARGET AUDIENCE
------------------------------------------------------------------------
PlaceWell is a companion app for a physical product line: premium, designed
QR-coded labels for home organization (pantry/spice jars, storage bins,
moving boxes, etc.). Customers buy printed labels (currently via Etsy),
each with a unique QR code. Scanning a label's QR code with the PlaceWell
app opens a digital entry for that specific label where the user records
what is stored there - item name, room/zone, an optional photo, and notes.

Problem it solves: physical labels alone go stale or vague ("Spices" tells
you nothing about what's actually in the jar today). PlaceWell lets users
keep a living digital record tied to each physical label, so a quick scan
instantly shows what's inside/behind that label, even if the physical
label text is generic or reused.

Target audience: home organizers, pantry/spice label buyers, moving/storage
customers, and (in a B2B channel) homebuilders/realtors offering PlaceWell
label kits as move-in gifts. It is a consumer utility app tied 1:1 to
purchased physical labels - it has no value as a standalone app without the
labels, similar to how a smart-home app is paired with hardware.

4. SETUP / ACCESS INSTRUCTIONS
------------------------------------------------------------------------
No login, account, or credentials are required - PlaceWell has no
authentication system. Personal inventory data entered by the user,
including contents, notes, rooms, zones, freshness information, and photos,
is stored locally on the user's device. The app uses the PlaceWell QR
Service only to validate issued physical labels and retrieve non-personal
label/order metadata. To fully review the app:

1. Launch the app -> you land on the Home screen (empty state on first
   launch, with a prompt to scan a label or add one manually).
2. Tap the Scan (camera) button -> grant camera permission when prompted.
3. Scan any QR code on the attached REVIEW-SHEET-all-qr.png (no physical
   label is needed; display the attachment on a second screen or print it)
   -> the app opens the correct screen for that label type
   (Setup for a new label, Detail/Recall for an existing one).
4. Alternatively, tap "Add Label Manually" from the Home screen drawer to
   create a label without scanning anything.
5. Fill in a name, room/zone, optional photo -> Save -> label appears on
   Home.

We have attached REVIEW-SHEET-all-qr.png, which contains six valid demo QR
codes covering Setup, Recall, Detail, and Order QR bulk import.

------------------------------------------------------------------------
5. EXTERNAL SERVICES / TOOLS
------------------------------------------------------------------------
PlaceWell uses the following external services/platforms:

- PlaceWell QR Service, hosted on a Linode server at placewell.app. It
  validates issued QR labels, retrieves label/order metadata, supports
  Order QR bulk import, and provides app deep-link/download fallback pages.
- Google Cloud Firestore stores non-personal issued-label metadata such as
  label ID, printed label name, category, SKU, order association, status,
  and aggregate scan counters. It does NOT store user-entered inventory
  contents, notes, room/zone assignments, freshness data, or photos.
- Apple App Store/TestFlight and Google Play distribute the mobile app.
- Standard Expo/React Native device modules provide camera access, Apple's
  photo picker/photo library access, haptic feedback, and local audio.

PlaceWell does not use account/authentication services, payment processors,
subscriptions, advertising SDKs, AI services, or cross-app tracking.
